                    PROYECTO: APP MÓVIL DE ESTUDIO PERSONALIZADO
═══════════════════════════════════════════════════════════════════════════════

DESCRIPCIÓN GENERAL
───────────────────
Aplicación móvil que permite a estudiantes (especialmente PAU/Selectividad en 
Catalunya) crear métodos de estudio personalizados a partir de:
  • Apuntes propios (PDFs, imágenes)
  • Currículums oficiales descargados
  • Exámenes reales de selectividad
  
La app genera automáticamente resumenes, flashcards y métodos de estudio 
personalizados según la rama académica (STEM, Humanidades, Técnicas, etc.)


═══════════════════════════════════════════════════════════════════════════════
                                FUNCIONALIDADES
═══════════════════════════════════════════════════════════════════════════════

MODO 1: ESTUDIO PERSONAL (Upload y procesamiento en la nube)
────────────────────────────────────────────────────────────
1. Usuario sube apuntes/temario desde React Native (PDF, imágenes, documentos)
2. FastAPI + LlamaIndex procesan el documento en el servidor
3. Claude (LLM) extrae contenido y genera:
   - Resumen estructurado
   - Flashcards (pregunta-respuesta)
   - Método de estudio según rama
4. TODO se guarda automáticamente en Supabase:
   ├─ PDF original → Supabase Storage
   ├─ Resumen → PostgreSQL
   ├─ Flashcards → PostgreSQL
   ├─ Método de estudio → PostgreSQL
   ├─ Vectores del contenido → pgvector (búsqueda semántica)
   └─ Metadata (fecha, rama, usuario) → PostgreSQL
5. React Native obtiene datos desde Supabase en tiempo real
6. Usuario accede desde cualquier dispositivo (sincronización automática)


MODO 2: CATÁLOGO OFICIAL (Búsqueda y descarga de currículums)
──────────────────────────────────────────────────────────────
1. Usuario busca desde React Native: "Selectividad Catalunya - Matemáticas 2024"
2. FastAPI obtiene:
   - Currículum oficial de la Generalitat (web scraping)
   - Exámenes reales pasados de selectividad
   - Temas por asignatura
3. Se procesa igual que Modo 1 (LlamaIndex + Claude)
4. TODO se guarda en Supabase como "Paquete Oficial":
   ├─ PDF/Documentos → Supabase Storage
   ├─ Resumen → PostgreSQL
   ├─ Flashcards → PostgreSQL
   ├─ Vectores → pgvector
   └─ Metadata (oficial, año, asignatura) → PostgreSQL
5. El paquete se descarga una sola vez en Supabase (todos los usuarios acceden a la misma copia)
6. Usuario lo agrega a su biblioteca en Supabase
7. Accede desde cualquier dispositivo (sincronización automática)

═══════════════════════════════════════════════════════════════════════════════
                            TECNOLOGÍAS DEFINITIVAS
═══════════════════════════════════════════════════════════════════════════════

CLIENTE MÓVIL (Online-First)
───────────────────────────
✅ React Native + Expo
   → Multiplataforma (iOS/Android)
   → Desarrollo más rápido
   → Hot reload
   
Dependencias recomendadas:
  • React Query / TanStack Query (manejo de datos desde Supabase)
  • Zustand / Redux (estado global temporal)
  • React Native Paper (componentes UI)
  • React Navigation (navegación)
  • Supabase Client (conexión a base de datos)

Características:
  ✅ Conexión en tiempo real con Supabase (Realtime subscriptions)
  ✅ Interfaz para subir documentos
  ✅ Búsqueda de paquetes oficiales
  ✅ Visualización de resumenes, flashcards, métodos de estudio
  ✅ Sincronización automática entre dispositivos
 
BACKEND (Procesamiento)
──────────────────────
FastAPI (Python)

Dependencias clave:
  • LlamaIndex (orquestación de documentos y LLMs)
  • OpenAI / Anthropic SDK (para llamar a Claude/GPT)
  • python-pptx / PyPDF2 (parsear documentos)
  • Tesseract-OCR (extraer texto de imágenes escaneadas)
  • Requests/BeautifulSoup (web scraping)
  • Celery + Redis (tareas asincrónicas para scraping)
  • python-dotenv (gestionar variables de entorno)


DATABASE + VECTORES
──────────────────
Supabase (Reemplaza Firebase + Pinecone)
   PostgreSQL (datos estructurados)
   pgvector (búsqueda vectorial semántica)
   Auth integrada
   → Storage para archivos
   → Realtime subscriptions
   
EXTRACCIÓN DE TEXTO
──────────────────
✅ LlamaIndex
   → Maneja múltiples formatos (PDF, DOCX, TXT, imágenes)
   → Chunking inteligente de documentos largos
   → Integración nativa con Supabase/pgvector

✅ OCR (Tesseract)
   → Para documentos escaneados
   → Para imágenes con texto

✅ Web Scraping
   → BeautifulSoup + Requests
   → Scrapy (si es complejo)
   → Descargar currículums de: educacio.gencat.cat


LLM (Generación de contenido)
────────────────────────────
✅ Claude 3 (Anthropic) - RECOMENDADO
   → Mejor para procesar documentos largos
   → Excelente generación de resumenes
   → Respuestas estructuradas y consistentes
   → Mejor relación precio-calidad

Alternativa:
   ⚠️ GPT-4 (más caro pero también bueno)
   ⚠️ Llama 2 (gratis pero menos preciso)


═══════════════════════════════════════════════════════════════════════════════
                  FLUJO DE DATOS (Modo 1 - Estudio Personal)
═══════════════════════════════════════════════════════════════════════════════

1. USUARIO CARGA APUNTES DESDE REACT NATIVE
   └─ React Native: selecciona PDF/imagen
   └─ Envía a FastAPI mediante HTTP POST

2. PROCESAMIENTO EN FASTAPI
   ├─ Valida formato y tamaño del archivo
   ├─ LlamaIndex carga el documento
   ├─ Extrae texto (con OCR si es imagen)
   └─ Chunking inteligente de contenido

3. GENERACIÓN CON CLAUDE
   ├─ Prompt 1: "Crea un resumen estructurado"
   ├─ Prompt 2: "Genera 15 flashcards (pregunta/respuesta)"
   ├─ Prompt 3: "Sugiere método de estudio para [RAMA]"
   └─ FastAPI obtiene respuestas de Claude

4. ALMACENAMIENTO TOTAL EN SUPABASE
   ├─ PDF original → Supabase Storage
   ├─ Metadata (titulo, rama, fecha) → PostgreSQL tabla "documentos"
   ├─ Resumen → PostgreSQL tabla "resumenes"
   ├─ Flashcards → PostgreSQL tabla "flashcards"
   ├─ Vectores de contenido → pgvector (búsqueda semántica)
   └─ Relación usuario-documento → PostgreSQL

5. SINCRONIZACIÓN EN TIEMPO REAL
   ├─ React Native se suscribe a cambios en Supabase Realtime
   ├─ Recibe datos apenas se guardan en base de datos
   └─ Muestra resumenes, flashcards, métodos al usuario

6. ACCESO DESDE CUALQUIER DISPOSITIVO
   ├─ Usuario abre app en otro teléfono/tablet
   ├─ Se conecta con su cuenta (Supabase Auth)
   ├─ Ve todos sus documentos procesados
   └─ TODO sincronizado automáticamente


VENTAJA: No hay duplicación de datos, no hay conflictos, no hay sincronización manual.


═══════════════════════════════════════════════════════════════════════════════
                 FLUJO DE DATOS (Modo 2 - Catálogo Oficial)
═══════════════════════════════════════════════════════════════════════════════

1. USUARIO BUSCA CURRÍCULUM OFICIAL DESDE REACT NATIVE
   └─ Búsqueda: "Selectividad 2024 - Matemáticas"

2. FASTAPI DESCARGA CONTENIDO OFICIAL (SI NO ESTÁ EN CACHÉ)
   ├─ Web scraping: educacio.gencat.cat
   ├─ Descarga PDF del currículum oficial
   ├─ Descarga exámenes reales pasados
   ├─ OCR para procesar documentos escaneados
   └─ Se descarga UNA SOLA VEZ (todo el mundo accede a la misma copia)

3. PROCESAMIENTO IGUAL A MODO 1
   ├─ LlamaIndex procesa
   ├─ Claude genera resumen, flashcards, métodos
   └─ FastAPI obtiene todo

4. ALMACENAMIENTO EN SUPABASE (como "Paquete Oficial")
   ├─ Documentos → Supabase Storage
   ├─ Metadata (oficial, año, asignatura) → PostgreSQL tabla "paquetes_oficiales"
   ├─ Resumen → PostgreSQL tabla "resumenes"
   ├─ Flashcards → PostgreSQL tabla "flashcards"
   ├─ Vectores → pgvector
   └─ Se marca como "descargable para todos los usuarios"

5. USUARIO DESCARGA PAQUETE OFICIAL
   ├─ React Native muestra paquete disponible
   ├─ Usuario toca "Descargar paquete"
   ├─ Se registra en tabla "user_paquetes" (relación usuario-paquete)
   └─ Aparece en su biblioteca

6. SINCRONIZACIÓN EN TIEMPO REAL
   ├─ React Native obtiene datos desde Supabase Realtime
   ├─ Muestra toda la información (resumen, flashcards, métodos)
   └─ Accesible desde cualquier dispositivo del usuario

VENTAJA: El paquete se procesa una sola vez. Todos los usuarios comparten la misma 
información. Cuando descargas, solo se registra tu relación con el paquete.


═══════════════════════════════════════════════════════════════════════════════
                          PERSONALIZACIÓN POR RAMA
═══════════════════════════════════════════════════════════════════════════════

Los prompts de Claude varían según la rama:

STEM (Matemáticas, Física, Química)
├─ Enfoque: Ejercicios prácticos, fórmulas clave, problemas resueltos
├─ Flashcards: Fórmula + Aplicación práctica
└─ Método: "Aprende fórmula → Resuelve 5 problemas tipo"

HUMANIDADES (Historia, Literatura, Filosofía)
├─ Enfoque: Contexto histórico, esquemas temporales, conceptos
├─ Flashcards: Concepto + Explicación breve
└─ Método: "Contexto → Tema → Análisis crítico"

IDIOMAS (Inglés, Francés)
├─ Enfoque: Vocabulario, expresiones, gramática
├─ Flashcards: Palabra/Frase + Traducción + Contexto
└─ Método: "Vocabulario → Frases → Conversación"

TÉCNICAS (Informática, Tecnología)
├─ Enfoque: Conceptos, diagramas, casos de uso
├─ Flashcards: Concepto + Implementación
└─ Método: "Teoría → Ejemplo → Práctica"

TU PROPUESTA INICIAL vs RECOMENDACIÓN FINAL:

ORIGINAL                          │ OPTIMIZADO
─────────────────────────────────┼──────────────────────────────────
React Native ✅                  │ React Native ✅

Pinecone ❌                       │ Supabase pgvector ✅
Firebase ❌                       │ Supabase PostgreSQL ✅
(no especificaste LLM) ❌         │ Claude (Anthropic) ✅

RAZONES DEL CAMBIO:

❌ Pinecone → ✅ Supabase pgvector
   • Pinecone es caro para MVP
   • Supabase pgvector hace lo mismo gratis/barato
   • Menos servicios que gestionar

❌ Firebase → ✅ Supabase
   • Firebase Auth: ambos lo tienen
   • Firebase DB: Supabase PostgreSQL es más poderoso
   • Firebase Storage: Supabase Storage es igual
   • Supabase agrega pgvector (Pinecone innecesario)
   • Supabase es más barato escalando
